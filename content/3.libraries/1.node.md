# Node / Bun

Use FreeStuff API in any JavaScript project using our official package.


## Install

::code-group
  ```bash [Bun]
  bun add freestuff
  ```
  ```bash [Yarn]
  yarn add freestuff
  ```
  ```bash [NPM]
  npm install freestuff
  ```
::

## Usage

See [GitHub](https://github.com/FreeStuffBot/api-wrapper-nodejs?tab=readme-ov-file#how-to-use) for how to use.

Or [open a PR](https://github.com/FreeStuffBot/docs) to add docs to this page.
