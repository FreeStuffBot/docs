# Node / Bun

::alert{type="danger"}
This API wrapper still only supports API v1. We are working on an updated version. Join our community on Discord to stay up to date!
::

Use FreeStuff API in any JavaScript project using our official package.


## Install

::code-group
  ```bash [Bun]
  bun add freestuff
  ```
  ```bash [Yarn]
  yarn add freestuff
  ```
  ```bash [NPM]
  npm install freestuff
  ```
::
